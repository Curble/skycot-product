# Seam manifest: `apps/nondev` ↔ upstream T3 Code

This fork adds a second browser client for non-developers at `apps/nondev`
(package `@t3tools/nondev`, served at `/simple/`). It is new files only, except
for the touches listed here. CI will enforce that **no other upstream file**
differs from `upstream/main` beyond this list. Keep every entry to the smallest
appended change so rebases stay mechanical.

Reasoning behind each touch is in the architecture report that produced this
plan (section 8, items B-1 to B-5). The desktop entry touch (B-6) is applied as
the `brand-client-entry*` seams in the brand table below.

## Brand seams: co-installable "SKYCOT" desktop shell

Identity values live in `nondev/brand.json`; `nondev/brand/env.cjs` turns them into `T3CODE_*`
environment defaults at process start (desktop: loaded from `boot.ts`; build script and CLI:
`node --import ./nondev/brand/env.cjs …`). Every code seam below reads
`process.env.X ?? <upstream default>`, so upstream's behaviour is unchanged when the variable is
absent and each line is a candidate upstream PR. `node nondev/scripts/apply-brand.ts` prints the
full constant → mechanism table and fails if a seam lost its marker, its variable or upstream's

## Safety seams: SKYCOT server-side policy (security audit 2026-10-21, SEC-01/SEC-03)

dependencies) and the server policy in `apps/server/src/skycot/`. Both are fork-owned additions

## Not touched (by design)

- `apps/mobile/**`, `packages/contracts/**`, `packages/client-runtime/**`:
  zero changes. `apps/web/**` carries only the B-7 footer item above. `apps/desktop/**` and `packages/shared/**` carry only the brand seams
  in the second table (every one a `process.env.X ?? upstreamDefault` line).
  Reuse happens through a Vite/TypeScript alias (`~` → `apps/web/src`, with
  `~/lib/utils` shimmed locally) and `@t3tools/client-runtime` subpath imports.
- `apps/server/src/**`: only the brand, safety and Family seams listed above. Routing under `/simple/` is hash-based so
  the SPA fallback (which serves the stock `index.html`) never fires for us.
- Root `vite.config.ts` lint overrides: our path gets none of the web lint
  rules yet (report item C-3); revisit once the client stabilises.

## How to check this manifest

```
git diff upstream/main --stat -- . ':!apps/nondev' ':!SEAM-MANIFEST.md' ':!pnpm-lock.yaml'
```

should list exactly the files in the two tables above and nothing else.
`node nondev/scripts/check-seams.ts --working-tree` enforces the same thing, and
`node nondev/scripts/apply-brand.ts` checks that every brand seam still reads its
variable and still carries upstream's default.
